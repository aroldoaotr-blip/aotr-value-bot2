Design the PRICE HISTORY PAGE ("/historico") of "AOTR Values", a premium trading-price platform for the game "Attack on Titan Revolution" (Roblox). Desktop 1440px, high-fidelity. Same design system as the approved home: deep-space dark theme, lavender primary (#cfbcff) and gold accents (#e7c365), surface #141218, glassmorphism, 3D depth, subtle animated grid, Space Grotesk headings, Inter body, JetBrains Mono data.

## CONTEXT
The user explores how item prices evolved over time. Each item has a history for BOTH sources (Oficial green / Tradeo blue), recorded every sync (30 min). Values in 3 currencies: 🔑 keys, 📜 scrolls, 🎭 vizard.

## LAYOUT (top to bottom)
1. Navbar (same as home).
2. Header: title "Histórico de Precios" + subtitle + the Oficial|Tradeo pill toggle.
3. TOOLBAR: item search with suggestions (icon + name), a currency selector as small pills (🔑 Llaves / 📜 Pergaminos / 🎭 Vizard), and a time-range selector (24h / 7d / 30d / 90d).
4. MAIN CHART CARD: big glass card with:
   - selected item icon + name + current price (big, in selected currency) + change badge (+/- % with green/red).
   - a large smooth AREA CHART with gradient fill, hover tooltip showing date + value, animated draw-in.
5. STATS ROW: 4 small glass cards — máximo, mínimo, promedio, variación (24h) for the selected range.
6. HISTORY TABLE (optional, collapsible): recent syncs with timestamp, value, change.
7. Footer.

## STYLE
Dark sci-fi, glass, glow, animated chart, 3D depth, high legibility. The chart is the hero of the page.

## RULES
- ALL UI text in SPANISH.
- Realistic values and dates (e.g. Azure Flames 🔑 850 → 901 over 30 days).
