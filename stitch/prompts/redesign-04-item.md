Design the ITEM DETAIL PAGE ("/item/:slug") of "AOTR Values", a premium trading-price platform for the game "Attack on Titan Revolution" (Roblox). Desktop 1440px, high-fidelity. Same design system as the approved home: deep-space dark theme, lavender primary (#cfbcff) and gold accents (#e7c365), surface #141218, glassmorphism, 3D depth, subtle animated grid, Space Grotesk headings, Inter body, JetBrains Mono data.

## CONTEXT
The user clicked an item (example: "Azure Flames") and lands on its detail page. The page compares the item across BOTH price sources: OFFICIAL (green) and TRADE (blue). The global toggle highlights the active source panel. Every price shown in 3 currencies: 🔑 keys, 📜 scrolls, 🎭 vizard.

## LAYOUT (top to bottom)
1. Navbar (same as home).
2. Breadcrumb: "Precios / Azure Flames".
3. HERO CARD: big item icon (image from aotrvalue.com, fallback initials badge), item NAME in display font, category, rarity badge (Mythic = red), demand bar (▰▰▰▰▱▱), and the THREE prices prominently (🔑 keys · 📜 scrolls · 🎭 vizard) with the primary emphasized. "Actualizado hace X min" badge.
4. TWO SOURCE PANELS side by side: "Oficial" (green accent) and "Tradeo" (blue accent) — the active one has a glowing ring/border. Each panel shows: the 3 prices of that source, demand, rate of change (Stable/Rising/Falling), taxes (💎 gem tax / 🪙 gold tax), status (Obtainable...), obtained from, prestige. 
5. PRICE HISTORY: a big glass chart card "Histórico de precios" with a line/area chart (sparkline-style) and a currency selector (keys/scrolls/vizard) as small pills.
6. Similar items (±10%): 3 small cards.
7. Footer.

## STYLE
Same as the approved home: dark sci-fi, glass panels with glow, hover animations, 3D depth, animated chart, staggered entrance. High legibility.

## RULES
- ALL UI text in SPANISH.
- Realistic values: Azure Flames ≈ 🔑 900 · 📜 300 · 🎭 1.
- Chart must look like real data (smooth area chart with gradient).
