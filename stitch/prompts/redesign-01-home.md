Design the HOME PAGE of "AOTR Values", a premium trading-price platform for the game "Attack on Titan Revolution" (Roblox). Desktop 1440px, high-fidelity.

## CONTEXT
Users look up item prices from 2 sources: an OFFICIAL price list (from the AOTR Google sheet, branded GREEN) and a TRADE price list (from an external API, branded BLUE). Every item shows 3 currencies: keys (🔑), scrolls (📜) and vizard (🎭). The platform syncs prices every 30 minutes and is used by traders of the AOTR community.

## THE 2 COLOR PALETTES (IMPORTANT — define both as part of this design)
Create a coherent brand identity with two themes and state exact hex colors:

1. **"Espacio" (dark)**: deep near-black navy base with indigo and cyan radial glows, neon accents, glass panels. Readable off-white text. Premium sci-fi, not generic.
2. **"Ceniza" (light, warm)**: inspired by Attack on Titan's embers and ash — warm cream/stone surfaces, ember red and burnt-orange accents, dark ink text. Cozy but high-contrast and readable.

Both palettes must be distinct yet feel like the same brand. Use the palette for this screen (dark theme as the primary render).

## STYLE — 3D + ANIMATION (IMPORTANT)
- Real sense of DEPTH: a perspective 3D grid floor that slowly scrolls, layered glass panels floating at different heights, parallax on hover, glowing particles drifting.
- ANIMATIONS: smooth motion everywhere — floating elements, pulsing glows, animated gradient text, hover transitions with glow, animated counters, shimmer effects. Feel alive but elegant.
- Glassmorphism panels with neon glow borders, soft shadows, generous whitespace.

## COMPONENTS
- **Navbar**: glowing orb logo with "AOTR VALUES" wordmark, nav links (Inicio, Precios, Comparar, Histórico), a pill toggle "Oficial | Tradeo" (green active state / blue), a theme-switch icon, and a small "sync" status badge with relative time.
- **Hero**: cinematic background (3D grid + particles + faint colossal-titan silhouette in the mist), a huge gradient display title "AOTR VALUES", a Spanish subtitle, and a prominent glass search bar with a live item preview (item icon + name + its value).
- **Stats strip**: 3-4 animated counters (items tracked, price sources, updates per day).
- **Top movers**: small glass cards with sparklines and green/red percentage deltas.
- **How it works**: 3 steps in glass cards (two sync scripts → two price lists → two price histories).
- **Footer**: brand + links.

## TYPOGRAPHY
Technical geometric display font for headings (like Orbitron; Space Grotesk is acceptable if Orbitron is unavailable), Inter for body, monospace for data values.

## RULES
- ALL UI text in SPANISH. No lorem ipsum or generic placeholders.
- High legibility in both themes.
- The AOTR world: subtle references to titans, walls and embers — tasteful, not kitsch.
- Memorable, bold, modern — NOT a generic SaaS dashboard.
