Design the TRADE COMPARATOR PAGE ("/trade") of "AOTR Values", a premium trading-price platform for the game "Attack on Titan Revolution" (Roblox). Desktop 1440px, high-fidelity. Same design system as the approved home: deep-space dark theme, lavender primary (#cfbcff) and gold accents (#e7c365), surface #141218, glassmorphism, 3D depth, subtle animated grid, Space Grotesk headings, Inter body, JetBrains Mono data.

## CONTEXT
A trader wants to know if their offer is FAIR. They build two stacks of items: "Tu oferta" (your side) and "Su oferta" / "Mi oferta" (the other side). The tool sums the total value of each side and shows the DIFFERENCE with a verdict: JUSTO (fair) / GANAS (you win) / PIERDES (you lose). Values computed in the 3 currencies: 🔑 keys, 📜 scrolls, 🎭 vizard. Sources: Oficial (green) / Tradeo (blue) — synchronized with the global toggle.

## LAYOUT (top to bottom)
1. Navbar (same as home).
2. Header: title "Comparador de Ofertas" + subtitle in Spanish + the Oficial|Tradeo pill toggle.
3. TWO-SIDED SCALE (the centerpiece): two large glass panels side by side ("TU OFERTA" vs "SU OFERTA") with:
   - an item adder: search input + suggestions (item icon, name, price).
   - the added items as chips/rows (icon, name, value).
   - a running TOTAL per side in the 3 currencies, with animated counter.
   - between the panels: a VS badge and a BALANCE indicator (see-saw / scale with glow on the heavier side, or a diff pill).
4. VERDICT CARD: big result — DIFFERENCE (tu oferta − su oferta) in the 3 currencies + verdict badge (JUSTO 🟢 / GANAS 🔵 / PIERDES 🔴) with a short Spanish explanation line.
5. Footer.

## STYLE
Dark sci-fi, glass panels with glow, smooth animations (items animate in, totals count up, verdict glows and pulses), 3D depth (floating panels), high legibility.

## RULES
- ALL UI text in SPANISH.
- Realistic AOTR item names (Helos, Azure Flames, ODM Gear V2, Titan Serum...).
- The scale/balance visual must be intuitive and memorable.
