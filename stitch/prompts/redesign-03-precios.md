Design the PRICES EXPLORER PAGE ("/precios") of "AOTR Values", a premium trading-price platform for the game "Attack on Titan Revolution" (Roblox). Desktop 1440px, high-fidelity. Same design system as the approved home page: deep-space dark theme, lavender primary (#cfbcff) and gold accents (#e7c365), surface #141218, glassmorphism, 3D depth, subtle animated perspective grid, Space Grotesk headings, Inter body, JetBrains Mono for data.

## CONTEXT
This is the main browsing page: hundreds of items, each with THREE prices (🔑 keys, 📜 scrolls, 🎭 vizard), from 2 sources — OFFICIAL list (green) and TRADE list (blue). The user can switch source with a global toggle. Items have rarity, demand and price trend.

## LAYOUT (top to bottom)
1. Sticky navbar (same as home: logo, links, Oficial|Tradeo pill toggle, theme icon).
2. Page header: title "Explorar Precios" + subtitle with the active source and item count (e.g. "398 ítems · hoja oficial").
3. TOOLBAR: the prominent pill toggle Oficial | Tradeo (green/blue active glow) at the very top, a search input, and a horizontal scrollable category chip row (filter).
4. RESULTS: a responsive grid of ITEM CARDS. Each card shows: item icon (image from aotrvalue.com, fallback: initials badge), item name, category under the name, rarity badge with color, DEMAND bar (▰▰▰▰▱▱), and the THREE prices in a clear row (🔑 keys · 📜 scrolls · 🎭 vizard) with the primary currency emphasized. Active source colors the card accent (green ring = oficial, blue ring = tradeo).
5. Footer.

## STYLE
Dark sci-fi, glass cards with glow borders, hover lift + glow, smooth entrance animations (staggered fade-up), subtle 3D grid background, animated counters on the header. High legibility, generous spacing.

## RULES
- ALL UI text in SPANISH. Use realistic AOTR item names (e.g. Helos, Azure Flames, ODM Gear V2, Titan Serum, Colossal Crystal).
- Prices realistic: keys can be thousands, scrolls hundreds, vizard decimals (e.g. 🔑 1.800 · 📜 600 · 🎭 2).
- Rarity colors: Mythic = red, Legendary = orange, Epic = violet, Rare = blue, Uncommon = green, Common = gray.
